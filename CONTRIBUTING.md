# Contributing to LoomMode

LoomMode has no independent website. Its actual GitHub repository will be the
public entry and Issues/PR channel after creation and Owner approval; no URL is
supplied before it exists. The public developer/copyright name is 争流儿. This file does not authorize publishing a repository or
operating another user's project.

For an Issue, give the goal, expected/actual behavior, relevant versions and a
small reproducible example. Explain which checks actually ran. Redact credentials,
personal paths, account data and private project records. Do not post sensitive
security details publicly; use an established authorized private contact. A
dedicated security contact is not yet announced.

For a Pull Request, keep the change focused, explain the problem and resulting
behavior, document compatibility changes and run the relevant directed tests.
For candidate offline checks use the installation guide and
`tools/agent_test_verify.py` with new external evidence and short fixture roots.
Do not blindly run live integration/model workflows. Preserve permission,
current-Context, Writer, evidence, resource and result gates; tests must not obtain
their expected result by disabling a production guard. Keep changes and logs
reviewable, and state any failure or unverified limitation.

Identify third-party code/assets and their source, license and notices before
including them. Do not submit materials you lack permission to contribute or
relicense other people's assets/data. Contributions intentionally submitted for
inclusion follow Apache License2.0 section5, unless explicitly stated otherwise
in a separately accepted arrangement. No CLA, DCO, copyright assignment or
invented rights holder is required by this guide.

Project code licensing is described in LICENSE. Names, marks and logos follow
TRADEMARK.md; truthful citation and descriptive promotion are welcome, while
impersonation and false official endorsement are not.
