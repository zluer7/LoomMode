## Supported use and evidence boundary

First public scope: Windows, Codex-only, bounded managed single Task, manual
progression, no automatic Git commit. Start with automatic=false, issue one
advance at a time and wait for the original worker to join. After actual
TASK_ACCEPTED at COMMIT_AUTHORIZATION, stop advancing and close the same Host
normally. Host CLOSED does not mean TASK_COMPLETE, Git checkpoint, Stage/Owner
acceptance or permission to resume a closed run.

Prior offline and bounded live evidence is reused only for unchanged bytes.

the limited path. Independent second physical-device identity remains unproven.

the Owner dossier; no new model run, cross-device test or long window is claimed.
