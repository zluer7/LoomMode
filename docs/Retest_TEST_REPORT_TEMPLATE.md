# 跨设备验证报告模板（只填实际结果）

- 结果：OFFLINE_PASS / REAL_TASK_PASS / FAILED / BLOCKED；不以安装或关闭退出0代替 Task Gate。
- 实际核心 ZIP 名称/大小/SHA256、Manifest/SHA256、源码摘要、wheel 哈希/版本；HANDOFF 身份是否相符。
- 本次设备/Windows/Python/Git/Codex 版本和实际普通用户环境；是否确认另一物理设备。
- 新项目/Stage/唯一 Task/caller、实际 Owner 原文、资源起止 UTC/次数/每次/总时长；旧运行不继承。
- 安装/导入来源、真实定向测试数量、失败/跳过、CLI/canonical/Writer 清理及原始命令日志。
- 实际 auth_mode；请求 model/effort；Context 返回 model/effort；turn/start 明确值，分别记录，未采集写明。
- Provider/endpoint/catalog：只写实际脱敏证据；不读取凭据、不新开探测来补表。
- 如失败：原 HOST_STAGE_FAILURE 与 UNKNOWN 收据/State/Context 的实际获准内容、引用、原始哈希；
  transport_timing 阶段/有效 deadline/诊断前 elapsed/start sent/ack；终态是否可信、哪些仍 UNKNOWN。
- 实际 reserve/claim 消费、费用事实或 UNKNOWN、原安全关闭/进程/租约收据；不退款、不重放。
- 固定测试/执行报告/Promoter Gate 原始引用；未到达即“未到达”，不得填 TASK_ACCEPTED。
- 每项问题的确认/推断/未验证状态；修改 diff、候选是否仍匹配原 Manifest；不得覆盖原件。
- 证据目录/ZIP/校验；删节/重编码副本与原件哈希分别列出；未包含内容的清单和原因。
- 下一步需 Owner 决定事项；完成后停止，无产品 Git/发布/额外服务/第二任务。
